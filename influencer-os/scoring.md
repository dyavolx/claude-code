# Scoring

Adapted from the campaign kit's 100-point scorecard. Commitment (10 points) can't be judged from public data, so discovery scores out of 90.

## Pre-score (public data only, /90)
- Audience fit /30: basketball players, parents or coaches; country matches the mix
- Content fit /25: clear, repeatable basketball or family-practice format
- Engagement /20: real engagement and genuine comments, not followers alone
- Content quality /15: useful demonstration, clear, safe filming

## Decision
- Qualified: 68+ out of 90 and all hard gates pass
- Maybe: 50 to 67, or any gate/data unclear. Ali decides.
- Reject: under 50, or any hard gate failed
(Scaled from the kit's 75/55 cutoffs on 100; adjust if you want.)
Daily file = best 110-120 following the mix in commands.md: qualified first, labeled maybes only to fill.

## Daily CSV columns
creator_id, date_added, handle, profile_url, platform, niche, lane, followers, median_views_last10, engagement_rate, posts_last_30d, reels_last_30d, days_since_last_post, country, contact_route, evidence_urls, ad_rights_status, source, gate_flags, audience_fit_30, content_fit_25, engagement_20, quality_15, pre_score_90, decision, reason, personal_hook

- lane: coach / parent / sports
- ad_rights_status: unknown / to ask / yes / no (never assume yes)
- reason: one short line. personal_hook: one real, specific thing from a recent post. Never invent.
- Missing data: write "unknown" and put the field in gate_flags. Never include a child's details.

## Sheet-paste file (matches Ali's Sheet1)
Columns: Creator Name, Profile Link / Handle, Platform, Niche, Country, Follower Count, Leads Finding Date, Notes
- Leads Finding Date format: d/m/yy (for example 8/10/26)
- Notes: one short line (why qualified, lane, any flag). No child details.
- Same rows, same order as the daily CSV.
